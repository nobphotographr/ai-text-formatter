# 文章の間を、整える。

生成AIの下書きに混ざった不自然な空白や改行を、ブラウザ内だけで整える静的Webツールです。

## 特徴

- 処理内容をチェックボックスで直接選択
- 日本語同士の空白だけを削除する安全な初期設定
- 文末（。！？）ごとに空行を入れる設定
- URL、メールアドレス、Markdownリンク、インラインコード、コードブロックを保護
- 入力内容をサーバーへ送信しないローカル処理
- HTML貼り付けとリッチテキストコピー
- スマートフォン対応

## テスト

```bash
npm test
```

静的ファイルのため、任意のWebサーバーからそのまま配信できます。
